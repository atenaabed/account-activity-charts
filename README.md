
# User Transaction Charts

This repository contains a collection of scripts and tools to analyze and visualize user transaction data on our platform.  
I developed these scripts during internal company projects to track deposits, withdrawals, and swap transactions across user accounts handled by our traders.

📌 **Data Sources Used**  
The scripts process data collected from internal company databases and transaction logs, including:  

- User deposits and withdrawals  
- Swap transaction history    

📊 **What This Project Includes**  
The code in this repository demonstrates how to fetch, aggregate, and visualize:  

- Individual user deposits and withdrawals  
- Swap transaction counts per user  

🔧 **Technologies**  

- JavaScript / Node.js
- Chart libraries (Chart.js)  
- REST & RPC API calls (if external APIs used)  
- **OpenAI API** for data analysis, insights, and automation assistance  

🎯 **Purpose**  
The goal of this repository is to provide a clear framework for extracting, aggregating, and visualizing user transaction data, helping with internal analytics and preparing datasets for decision-making or further blockchain-related projects.
